# Nourish Next Bite

An ai diet tracker. Users should log meals in pure text form, ai then calculates everything and logs that in the database, database should track calories and all macro and micronutrients, the app should also maintain personalized daily targets for the user based on theirs height, weight, sex, activity and other relevant metrics, after each log ai should give the user a brief about what foods they should prioritize in their next meal to meet their targets
